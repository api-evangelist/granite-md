Granite provides an encrypted knowledge base and second brain for teams, offering plain Markdown notes, live co‑editing, SSO, audit logs, and secure AI access via the Model Context Protocol. It supports granular permissions, compliance features, and integrates with Claude, ChatGPT, and other AI assistants, targeting both individuals and enterprises.

**Areas:** KnowledgeBase · AI · Collaboration · Security · Encryption

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Granite: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
